# Aye Yandanar Kyaw — Portfolio

Personal portfolio site: supply chain analytics, process automation (Excel VBA, Python, SQL) and Power BI dashboards.

Built as a single static page (`index.html`) and hosted on GitHub Pages at https://vivian-mar.github.io.

## Run locally

Open `index.html` in any browser. No build step.

## Update

Edit `index.html` and push to the `main` branch. GitHub Pages republishes automatically within a minute or two.
